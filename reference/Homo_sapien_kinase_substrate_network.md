# Homo_sapien_kinase_substrate_network

A prior knowledge database about the known kinase-phosphosite
interactions for Homo sapiens

## Usage

``` r
data(Homo_sapien_kinase_substrate_network)
```

## Format

a data.frame object

## Value

A `data frame` containing the information about the known
kinase-phosphosite interactions for Homo sapiens.

## Examples

``` r
data(Homo_sapien_kinase_substrate_network)
```
