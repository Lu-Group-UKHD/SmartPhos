# dda_example

A sample of Data Dependent Acquisition (DDA) mass spectrometry data from
Max Quant.

## Usage

``` r
data(dda_example)
```

## Format

a class S4 object of MultiAssayExperiment

## Value

A `MultiAssayExperiment` object containing a sample of DDA mass
spectrometry data from Max Quant.

## Examples

``` r
data(dda_example)
```
